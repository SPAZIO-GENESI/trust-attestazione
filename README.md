⚠️ **Non modificare nulla qui.** Il contenuto di questo repository è **generato**
dal monorepo [`SPAZIO-GENESI/gtf`](https://github.com/SPAZIO-GENESI/gtf) e
sovrascritto a ogni pubblicazione: qualunque modifica fatta direttamente qui
viene persa al prossimo deploy, senza avviso.

Questo repo esiste solo per servire, tramite GitHub Pages, il Trust Center del
servizio di attestazione su **https://attestazione.trust.spaziogenesi.org** —

sottodominio non è ottenibile dal repo `gtf`, che pubblica già la radice
`trust.spaziogenesi.org`.

Il sorgente, il registro e i generatori vivono in `gtf`:
`tenants/attestazione/` per i dati del progetto, `core/` per il motore.
